# V11.2 平地前伸修复 — 2026-09-27

目标：保持既有 20–44 cm、4 cm 间隔踏深和既有高度范围，支持任意前腿先落 B1、支撑后对侧落同级，不要求跨级交替；持续平地及上下楼出口避免四肢前伸匍匐。

## 已定位与修改

1. 训练默认腿角和部署默认腿角不一致，且旧 exporter 写出旧常量。`scripts/tools/m20_export_contract.py` 从 checkpoint 对应 `params/env.yaml` 读取真实默认角及各关节动作尺度，验证顺序后导出。V11 部署读取该 metadata，缺失或非法值拒绝运行。C++ 的观测减偏置、动作加偏置及缺观测保持姿态统一使用训练默认角。
2. `sim2sim.sh` 原默认训练仓库是另一目录。V11 的 PT 导出现在优先使用 checkpoint 所属仓库的导出器；用户原命令无需新增参数。
3. 原平地成本只覆盖高度、倾斜及晃动，真实前伸轨迹可以完全不触发高度成本。V11.2 新成本结合各轮相对髋关节的身体前向距离和关节偏离自由区，加入持续平地姿态惩罚及前进收益调制。自由区允许关节活动，不强制固定姿态；阈值唯一来源为 `M20V112HandoffCfg`。楼梯接触过程沿用原地形证据门控。

## 已执行验证及边界

- 独立 C++ synthetic ONNX 测试核对实际观测偏置与全部 16 个动作尺度；缺 metadata、NaN、乱序、负尺度均拒绝。launcher 实际构建、导出、加载、缺感知安全保持 PASS。
- 正常/单腿前伸、坐标平移、持续平地、非平地门控、禁用分支、非有限值测试 PASS。
- 旧权重真实前进记录：1040 个样本全部触发新 workspace 成本，而旧高度成本全部为零。这证明原漏罚被识别，不证明新策略已学好。
- 最终 40 环境、240 步 Isaac 冻结权重 rollout PASS，1195 个真实平地样本触发 workspace 成本；7 踏深、左右先导/重复先导及 V11.1 兼容检查 PASS。
- 实际 PPO 两次更新完成（54300、54301），无非有限奖励/Traceback。早期 episode 指标为零不能当作步态验收。
- 独立同 family 代码复核通过；缺异构复核。未验证同一 common_step 内人工 reset 的缓存场景。
- **未完成新权重的长期纯平地、上楼出口、下楼出口及踏深×高度闭环行为验收。不能称匍匐已解决。**
