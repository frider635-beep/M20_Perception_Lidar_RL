# 上楼支撑信用结算修复

本轮只修已确认的信用采集错位，未重启训练。运行中的 Python 进程仍使用启动时版本。

- 准备窗口在 ascent 地形、双前轮接触时提前滚动采集；首次 strict target 获取不抹掉窗口。窗口仍只有最近5帧，离开准备条件会清除，seed 后换阶清除。
- 承重采集只要求所选落脚腿接触且 strict locked_support_steps > 0；不再要求对侧前腿同时接触。支撑多边形仍使用实际接触点，工作空间只评价承重腿。
- 缺准备/摆动/承重证据分别记录；缺证据不伪装成好质量。有效事件的证据完整率可在 AscentEntry 下监控。
- 原 min 三阶段结算保留，坏摆动不能靠落地等待稀释。

验证：新增首次锁定晚于准备、合法落地同时对侧起摆、缺准备不能获信用三种反例；混合踏深实际 Isaac mesh、缓存/换阶隔离、等待刷分、支撑质量、原任务配置、physical ledger 单测通过；py_compile 和 diff --check 通过。

未验证：本轮未跑 Isaac runtime/PPO smoke、checkpoint 回放或行为训练；不能宣称入阶动作已改善。没有启动或重启长训。

暂不改速度不足项：原生已存在 anchor confirmation 豁免。先修确定的信用断路，避免同步改目标后无法归因；有界入阶豁免及碰撞/加速度轨迹采集仍待后续验证。下楼、平地、Actor/Critic/PPO均未修改。
