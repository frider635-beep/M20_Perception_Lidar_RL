# V11.2 路线收益与支撑阶段修复

直接修改任务 M20-Stair-V11.2-VariableTread-v0。目标是同时保持愿意上楼、同阶先后支撑、平地不前伸及自然出口；任何一项失败不能以总奖励增加替代。当前是机制修复，不是新策略闭环通过。

## 改动

- v112_handoff：楼梯路线质量由回合锁定航向/起点计算，乘在线速度、偏航速度、世界前进正收益；目标消失和侧边平地不能解除。平台物理确认、后轮越过真实网格末级边界、横向回到有效路线后才锁存完成，随后平地转向不会重开楼梯路线约束。纯平地和下楼原路线逻辑保持。
- 取消“仅目标激活就降低驱动”的整段抑制。实际有时限支撑驻留时，线速度奖励改用安静支撑目标，前进奖励与欠速惩罚关闭；其它阶段恢复前进目标。策略观测、动作与用户命令不改。
- v11_continuous 的 V11.2 分支：物理双前轮同阶完成不再被风格 cycle_done 替代；换阶和平台确认也使用物理完成。严格顺序风格仍由独立 cycle_event 认证，不强制跨阶交替。V11.1 保持原行为。
- 风格完成事件新增按实际阶位置的每回合一次性账本；跳级blocked不付费、同阶重新获取不重复付费。已有渐进支撑奖励保留。
- 新增整回合物理pair事件数、已付风格次数、离路线帧占比及样本分母，避免只依赖瞬时event快照。它们仍需与实际接触/视频交叉验证。
- 持续平地workspace保持原实现；本轮未调阈值、未放松楼梯时序要求。所有新参数位于 M20V112HandoffCfg。
