# V11.2 后期绕楼梯：修改建议，尚未实施

用户报告同一 run 的 model_73200 在 sim2sim 绕楼梯，而 model_60000 不绕。此次只读核查保存配置、实际训练日志和历史修复记录，未运行两个权重的匹配闭环对照，也未修改/停止当前训练。

## 证据

60000、73200 各取此前100轮及本轮（101轮），原始均值落盘 artifacts/v112_avoidance_review_20260928/training_windows.json。总体奖励119.255→119.906；线速度奖励3.941→3.978；世界前进奖励0.786→0.797；同阶周期奖励约0.00005→0.00003。平地workspace成本0.01172→0.01324，并未显示后期持续改善。总体统计混合地形，不是匹配轨迹因果实验。

代码证据：world_forward_progress 在指定楼梯terrain列有正向速度即可计算收益；不要求当时位于有效flight横向范围，target不活跃时 anchor条件自动满足。已有横向及偏航罚项，不能称完全没有防绕行；它们是有界负项。cycle_drive在目标活跃时将速度相关收益降至0.6，驻留时0.25；无目标则1。flat blend确认平面后覆盖楼梯调制。于是离开楼梯目标并到侧边平地可能恢复更高稠密收益。该路径代码存在，但本次未测“绕行比正确上楼回报更高”的匹配轨迹，不能宣布唯一根因。

指标缺口：v11_event_reachability_metric 读取瞬时landing_event，忽略env_ids；tread_metric仅统计reset集合当前状态，不能替代整回合逐阶事件计数。打印0不能推断没有任何楼梯完成。terrain curriculum上楼已经要求platform_confirmed，不能称单靠绕行能晋级；但尚不足以堵住每步收益漏洞。

历史：V13–V13.5复盘出现速度收益增加、合法支撑事件稀少及内部代理误导；V11.1曾撤回整段周期速度抑制恢复V11-FD原上楼。V11.2为了新顺序要求重开周期，但不应再次让正确入阶损失持续收益而绕行恢复收益。上轮修复验证了语义一致和姿态成本触发，未完成正确上楼/绕行回报排序及长期训练行为回归，是验证缺项。

## 建议顺序

1. 保留两个权重，从60000作为候选起点，不能直接宣布其全面合格。匹配spawn、速度、噪声seed、模型默认角契约，分别测试纯平地/上楼/上下楼出口及固定宽高集合；逐帧记录路线偏差、接触、台阶id、workspace blend、各项收益。先核对检测器与真实物理事件。
2. 独立锁定训练任务路线和真实楼梯横向边界；感知目标消失不能解除尚未完成的穿越任务。正常平地姿态照常约束，但侧边绕行不计楼梯进度/成功，楼梯相关正收益与路线有效性联合核算。已有route-coupled函数可参考，不能直接整套V13搬回。
3. 拆开“真实双脚到同一级”和“符合先后支撑风格”事件；风格不合格不能抹掉已完成的物理运动事实。严格风格仍只奖励任意一腿承重后对侧承重，不要求下一阶换领先腿。审查target_active就减速的全段0.6调制，候选仅在实际支撑交接窗口调制；防止停住/绕开能恢复更多收益。
4. 保留纯平地全腿workspace；检查入口、混合支撑、最后后轮离阶期间误触发。以接触支撑与几何证据连续切换；真实回到平地后持续生效，不加出口超时。是否放宽自由区需用正常运动与失败运动对照决定，先不拍脑袋加权。
5. 按踏深和高度维护可达训练样本；先让当前权重能频繁经历正确入阶/单腿支撑/双腿支撑，逐渐收紧驻留和支撑质量。终态安全标准不放宽，训练shaping可渐进。不能继续只增加稀疏完成奖励。
6. 以整回合真实入阶、逐阶完成、绕行和出口后长期姿态分组选checkpoint，记录最差宽高组及分母；同一固定评估集监控后期退化，采用最佳通过模型而非最高迭代。无需先引入MoE/RNN/多critic。

建议另建隔离候选配置，保留V11.2对照；首先只改路线收益和周期事件分离，验收后再调整平地门控与课程，避免一次混入多项无法归因。此次没有实施新奖励或启动额外训练。
